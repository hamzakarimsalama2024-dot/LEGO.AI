# LEGO AI – مهندس الليجو الذكي

موقع ويب عربي يعمل على Google Chrome، مع خادم Node.js يحفظ مفتاح OpenAI بعيدًا عن المتصفح.

## الموجود في النسخة
- اختيار حجم المشروع: صغير / متوسط / كبير.
- بدء مشروع واقتراح الخطوة الأولى.
- زر «تم» لطلب الخطوة التالية.
- اقتراح بديل للقطعة.
- اقتراح لون بديل.
- شرح تفصيلي للخطوة.
- رفع صورة لتحليل تركيب الليجو بالذكاء الاصطناعي.

## تشغيله على الكمبيوتر
1. ثبّت Node.js إصدار 20 أو أحدث.
2. فك ضغط المشروع وافتح مجلده في Terminal.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى ملف اسمه `.env`.
5. ضع مفتاح OpenAI API في `OPENAI_API_KEY` داخل `.env` فقط.
6. نفّذ: `npm start`
7. افتح Chrome على `http://localhost:3000`

## تشغيله على الإنترنت
ارفع مجلد المشروع إلى خدمة استضافة تدعم Node.js (مثل Render).
اجعل أمر البناء `npm install` وأمر التشغيل `npm start`.
أضف متغيرات البيئة في لوحة الاستضافة:
- `OPENAI_API_KEY` = مفتاحك السري
- `OPENAI_MODEL` = `gpt-6.2-sol`
- `NODE_VERSION` = `20`

بعد النشر افتح رابط الموقع في Google Chrome.

## حماية المفتاح
- لا تضع المفتاح في `public/` أو `index.html` أو `app.js`.
- لا ترسله في المحادثات ولا ترفعه إلى GitHub.
- ملف `.env` مستثنى من Git بواسطة `.gitignore`.
- لا تنشر الخادم للعامة قبل ضبط حدود الاستخدام والحماية المناسبة.

## ملاحظات مهمة
- استخدام OpenAI API يحتاج حساب API ومفتاحًا وفوترة/رصيدًا منفصلًا عن اشتراك ChatGPT.
- هذه نسخة أولية قابلة للتشغيل؛ تحليل الصور والتعليمات يعتمدان على جودة الصورة ووصف القطع.
- زر التصوير يطلب من المتصفح اختيار/التقاط صورة؛ قد تختلف تجربة الكاميرا حسب الهاتف والمتصفح.
